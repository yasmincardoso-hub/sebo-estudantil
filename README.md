 📚 Sebo Estudantil

Um projeto criado para ajudar estudantes a encontrar e compartilhar materiais escolares e universitários.

 💡 Sobre

O Sebo Estudantil tem como objetivo facilitar a compra e venda de materiais de estudo, tornando-os mais acessíveis para outros estudantes.

A ideia é incentivar a reutilização de materiais que ainda podem ser úteis para outras pessoas.

 🚀 Funcionalidades

- Cadastro e login de usuários
- Cadastro de materiais
- Busca por materiais
- Categorias
- Contato entre usuários
- Gerenciamento de anúncios
